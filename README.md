# KPI-Finance
Interactive Finance KPI Dashboard created using Microsoft Excel to analyze revenue, profit, expenses, customers, budget performance, and departmental trends.

 📊 Finance KPI Dashboard – Excel

📌 Project Overview

This project is an interactive Finance KPI Dashboard created using Microsoft Excel.

The dashboard transforms financial data into a clear and interactive visual report to analyze revenue, profit, expenses, customer performance, budget performance, and departmental trends.

🎯 Key Performance Indicators

- 💰 Revenue
- 📈 Profit
- 💸 Expenses
- 👥 Customers
- ⭐ Customer Satisfaction Score

 📊 Dashboard Features

- Revenue vs Profit Trend
- Revenue by Department
- Revenue, Expenses & Profit by Department
- Budget vs Actual Analysis
- Expense Breakdown
- Top 10 Customers by Revenue
- Monthly Financial Analysis
- Region-wise Filtering
- Interactive Excel Slicers

 🗂️ Dataset

The dataset contains 500 financial records with fields including:

- Date
- Region
- Department
- Revenue
- Expenses
- Customers
- Budget Revenue
- Product Category
- Sales Channel
- Financial Metric
- Expense Category
- Customer Name

 🛠️ Tools & Skills

- Microsoft Excel
- Pivot Tables
- Pivot Charts
- Excel Formulas
- Slicers
- Data Analysis
- Data Visualization

 📌 Dashboard KPIs

The dashboard summarizes:

- Total Revenue: $85.07M
- Total Profit: $43.35M
- Total Expenses: $41.72M
- Total Customers: 441,374
- Customer Satisfaction Score: 87.47%

🎯 Project Objective

The objective of this project is to transform raw financial data into an interactive Excel dashboard that makes it easier to monitor financial performance, compare departments, analyze expenses, evaluate budget performance, and understand customer-related metrics.
